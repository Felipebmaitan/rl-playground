# RL Playground

Welcome to my RL sandbox.

This repo is where I am going to study RL by trying to build stuff with it. There's no guarantee anything here is good code, almost everything in this repo will be made with the help of AI, which really speeds up the learning.

I'm structuring this as a one project per folder repository, so under each folder there will be a different experimentation I'm running. All in the same repo so I don't need to keep creating one for everything I decide to test out.

## Structure

Each experiment should live in its own folder and have its own `README.md`.

```text
RL-Playground/
  README.md
  AGENTS.md
  some-rl-experiment/
    README.md
    src/
    configs/
```

I plan to log my trajectory and what I learn in the READMEs inside the folder of each project.
